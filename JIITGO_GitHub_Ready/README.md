# JIITGO

Student-focused cab-sharing platform for JIIT Noida.

## Tech stack
- Python / Flask
- Flask-SQLAlchemy
- Flask-SocketIO
- HTML, CSS and JavaScript

## Local setup
1. Create and activate a Python virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Set a strong `JIITGO_SECRET_KEY` environment variable.
4. Run: `python app.py`

The local SQLite database is intentionally excluded from this repository. A production database must be configured before public deployment.
